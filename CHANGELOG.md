- Snapshot deny-regex snake_case gap closed (roadmap debt D3): the pinned `\b(password|...)\b` word-boundary regex never fired on underscore-attached names (`db_password`, `access_token`, `SECRET_KEY`) because `_` is a word character, so JSONB cells with snake_case secret names survived layer-2 redaction whenever layer 1's structural exclusion did not cover them. `DENY_RE` in lib/snapshot-redact.js now uses variable-boundary lookarounds `(?<![a-z0-9])...(?![a-z0-9])` — letters/digits still block (`keyboard`/`monkeybusiness`/`keynote`/`tokens`/`secretSanta` unchanged), underscore counts as a boundary.
